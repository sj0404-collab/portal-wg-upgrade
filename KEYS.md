# Ключи: что за что отвечает

| Ключ | Для чего | Где |
|---|---|---|
| **APK signing** `keystore/androide.jks` | Установка/обновление приложения | не имеет отношения к VPN |
| **Interface PrivateKey** | Твой секрет туннеля | генерируется в редакторе (иконка ключа) или при новом туннеле автоматически |
| **Interface PublicKey** | Отдаёшь **серверу** | считается из PrivateKey |
| **Peer PublicKey** | Публичный ключ **сервера** | без него handshake не будет |
| **Peer Endpoint** | `host:port` сервера | без него пакеты некуда слать |
| **AllowedIPs** | какие сети в туннель | по умолчанию `0.0.0.0/0, ::/0` (весь трафик) |
| **PersistentKeepalive** | NAT не рвёт сессию | по умолчанию `25` |

VPN «мост» на GitHub runner **не поднимается**: у hosted runner нет стабильного публичного UDP и это не твой сервер. Нужен свой VPS с `wg-quick`.

Новый туннель в AetherWG сразу получает пару ключей, адрес `10.66.66.2/32`, DNS Cloudflare и keepalive 25. Остаётся вписать **Peer PublicKey + Endpoint** своего сервера.
